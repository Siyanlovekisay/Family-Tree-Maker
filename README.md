# Family Tree Maker

A simple website for building and keeping your family tree, made with plain HTML, CSS, and JavaScript. No installs and no server needed.

## Features
- Start from a template (Basic Family, With Grandparents, Extended Family) or from a blank canvas
- Add people with a name, birthday, and optional photo
- Connect people as partners, parents, children, or siblings, with lines drawn automatically
- Drag people around, select several at once, and zoom or pan the canvas
- Keep a Pictures folder and a Stories folder for each person
- Choose from several color themes
- Save in your browser, download the tree as an image (PNG), or download everything as a ZIP and open it again later

## How to use
Open `index.html` in a browser and click **Start from scratch** or pick a template.

## Your data
Everything is stored in your own browser. Nothing is uploaded to a server. To keep your tree safe or move it to another device, use **Save → Download as ZIP**, then **Open a saved ZIP** to load it again.

## Built with
HTML, CSS, JavaScript, and [JSZip](https://stuk.github.io/jszip/) for the ZIP files.

## Why I made this
Many families lose their history within a few generations because names and stories are never written down. This project is a small way to help families remember.
